# 蓝闪蝶壳 · 设计稿 v1（还在提方案，没接进 App）

- 母题是「结构色」：闪蝶的蓝不是颜料，是光打在鳞片上折出来的，换个角度颜色就变
- 深夜底色 + 一种会流动的虹彩蓝（只用在蝴蝶、天数、当前项、她的消息、发送键）；其余全是细线和留白
- 首页：一只代码画的闪蝶（黑边、白点、鳞片细纹）；N° 179 做成标本编号；学名标签写「采集于 在一起那天」；目录用 i. ii. iii. 罗马数字
- 聊天：他的消息是暗玻璃 + 一道虹彩边，她的消息是实心闪蝶蓝；头像是虹彩圈里的小蝴蝶
- 设想的手感：手机倾斜 → 翅膀和虹彩跟着变色；他有新消息 → 蝴蝶落下来；长按他 → 翅膀慢慢开合
